
# TaskFlow — Student Task Manager

A desktop task management application built using Python and Tkinter.

## Features
- Add tasks with deadlines
- Set Low, Medium, and High priorities
- Mark tasks as completed or undo completion
- Filter All, Pending, and Completed tasks
- Track total, pending, and completed tasks
- Delete tasks
- Save tasks locally using JSON
- Scroll through long task lists

## Technologies
- Python
- Tkinter
- JSON
- File Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python taskflow.py
```

## Learning Outcomes

Practiced Python functions, object-oriented programming,
GUI development, event handling, file handling,
JSON serialization, and input validation.
